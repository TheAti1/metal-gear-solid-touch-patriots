## What "proven" means

A function is proven when its recompiled C, linked against the original binary, and the original
machine code are run from the **same captured or constructed state**, and every observable effect
is identical:
- the return registers (r0/r1) as wide as the declared return type;
- every byte written to memory, except the run's own stack frame;
- the exact sequence of boundary calls with their arguments: GL (vertex data included), OpenAL,
  libc, framework messages.

Both runs execute in the same emulator (Unicorn) under the device's measured FPU mode (FZ+DN).
Uninitialised-stack reads are told apart from real differences by running twice with different
poison patterns. Results are tied to the exact binary tested: a fingerprint per function, so a
rebuilt function goes stale until it is re-tested.

## Defects the verification found and fixed

Each one was a real difference between the decompiled C and the binary. Each fix is general
(decompiler patch, export rule, recompile transform or binary-cited table), and where possible a
static check now closes the whole class.

| class | fix | closed by |
|---|---|---|
| float narrowing changed rounding | `subflow-exact.patch` (decompiler) | tests |
| float `+`/`*` treated as associative | `printc-float-nonassociative.patch` | tests |
| float<->int bit reinterpretation printed as conversion | export `__BITCAST`, clang `-Wfloat-conversion` pass | compile report |
| integer compare of float-typed operands | export `__BITCAST(int, ...)` | tests |
| VFP register spill helpers clobbered arguments | call-fixup (`sp -= 64`) | V0 audit (argv recovered) |
| integer division semantics (x/0, INT_MIN/-1) | measured-semantics shims | tests |
| 64-bit CONCAT/SUB of floats | bit-level `__U64` | tests |
| variadic calls lost their arguments | ApplyVarargCallsites (format string -> exact words) | tests |
| inferred return types | AnalyzeReturnUse (binary call sites never read r0/r1) | ledger rule |
| constant printed as a function name | exact literal | tests |
| **stret buffer read after a later call** (RayMissile) | `stret_dead.tsv` + transform 1i | **CheckAddrTiedMerge** over all 1,395 functions: 1 real, 3 false positives reviewed |
| untyped call with a phi selector (drebin_drawBar) | `msgsend_site_protos.tsv` + transform 1j | 5 remaining untyped sites pass word-only arguments |
| **distinct CFStrings collided in C names** (`","` vs `":"`) | export uses the address-unique name | 38 references, 0 unresolved |
| **64-bit method arguments in the wrong storage** (NSTimer interval) | ApplyCallsiteSignatures: f8/i8 as two APCS words | all 3 double-argument sites in the program |
| `return x;` deleted by the recompiler's stack-frame overlay (`Sound::ready`, `SoundService::init`) | STACK_VAR rejects statement keywords | only these 2 functions had the artifact |
| **C++ class size from `this` accesses only** (`Sound` 0x39; the binary allocates n * 0x3c), found by the port | `cpp_sizes.tsv` + SizeCppClasses | the struct-stride pattern `&p[1] + k` occurs nowhere else |
| **float returned as `undefined4`, converted by callers** (sound volumes: 1.0 -> 1.065e9), found by the port | `float_returns.tsv` + ApplyFloatReturns (4 functions) | scan: no other integer-typed function returns float bit patterns, no other `(float)f()` on an integer return |
| ledger: a pass row outranked a "return-unverified" row of a function whose return IS used | such rows now count as **fail** unless the function is (proven) void | re-ranked the whole ledger: no further failures |

## Remaining work toward an exact port

The gate covers the decompilation. An exact port also needs:

0. **Raise test coverage.** Measured 2026-10-10 (`test_coverage.md`, `tools/mgst_testcov.py`):
   passing tests executed **45.0 %** of the instructions of proven functions, and 684 functions
   are at 100 %. The largest gaps are the scene state machines and loaders (`GameScene`,
   `title_load`, `sh_load`, `loadStageData`), which run at scene transitions the snapshots
   rarely catch. Best closed by the port's frame-by-frame comparison against the emulator,
   plus targeted captures (Survival mode injection: `SURVIVAL=` in `mgst_campaign.sh`).
1. **Stronger evidence for the 575 synthetic-only functions.** Natural states, from more
   emulator tours (shop interior, Survival, the remaining menu scenes) or from the port itself:
   once the port runs, every function can be compared frame by frame against the emulator.
2. **V0 functions in the port:** SjLj frames become `try/catch`; entry and dyld are replaced by
   the Android runtime.
3. **Platform exactness** (`analysis/port/platform_api.md`): Darwin `random()` bit-exact; iOS
   libm `sinf`/`cosf`/`atan2` agreement; FZ+DN float mode; runtime text textures captured from the
   emulator; CgBI textures kept premultiplied; the IMA4 music decoder checked against Apple's.
4. **Memory model** (decided 2026-10-09): **A**, armeabi-v7a with the original image at its
   original addresses, first; then **B**, arm64 with a 32-bit memory arena, for 64-bit-only
   devices and other systems.
